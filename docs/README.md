# Project documentation

Project documentation is grouped by purpose:

- [Architecture](architecture/ARCHITECTURE.md): application layers, workflow, and deployment structure.
- [Runbooks](runbooks/): authentication and deployment procedures.
- [Engineering notes](engineering/): verified fixes and quality or speed improvements.
- [Evaluation plan](evaluation/OFFLINE_EVALUATION_PLAN.md): offline and RAGAS evaluation.
- [Operations](operations/PRODUCTION_READINESS.md): production readiness checklist.
- [Planning](planning/revamp.md): longer-term project direction.
- [Specifications](specifications/opencodereview-spec.md): project specification snapshot.
- [AI engineer interview guide](project-guide/README.md): guide files, diagrams, and regeneration steps.

The guide's generated page images and preview files belong in its ignored `working/`
directory. Machine-specific diagnostics and test checkpoint data belong under `.local/`.
